# Алсу — сайт риэлтора

Персональный сайт с услугами, фотографиями клиентов, каруселью отзывов, выбором мессенджера и ипотечным калькулятором.

**Сайт:** [alsu-rieltor.ru](https://alsu-rieltor.ru/)

## Локальный запуск

Откройте `index.html` в браузере или запустите из папки проекта:

```sh
python3 -m http.server 8000
```

Затем откройте [localhost:8000](http://localhost:8000). Сборка и установка зависимостей не требуются.

## Структура

- `index.html`, `styles.css`, `script.js` — основные разделы, оформление и взаимодействия
- `assets/` — фотографии, отзывы, логотип и иконки
- `reviews.css` — адаптивная карусель отзывов
- `mortgage-core.js`, `mortgage-ui.js`, `mortgage.css` — расчёт, форма и график платежей
- `mortgage-config.js`, `mortgage-analytics.js` — настройка и отправка статистики
- `analytics/Code.gs` — обработчик Google Apps Script
- `analytics/README.txt` — установка и ограничения аналитики
- `tests/mortgage.test.cjs` — проверки калькулятора и аналитики
- `README.txt` — подробное описание проекта

## Проверки

Нужен Node.js 18 или новее, дополнительные пакеты не требуются:

```sh
node --test tests/mortgage.test.cjs
```

## Публикация

GitHub Pages публикует корень ветки `main`. Файл `.nojekyll` отключает обработку Jekyll. После изменений отправьте коммит в `main` и дождитесь завершения развёртывания Pages.

Файл `CNAME` закрепляет домен `alsu-rieltor.ru` за сайтом. Сохраняйте его при следующих публикациях. DNS обслуживается в REG.RU; `www` направляется на тот же сайт. HTTPS-сертификат выпускает GitHub Pages.

## Аналитика

Успешное нажатие «Рассчитать» отправляет параметры и результат в закрытую Google Таблицу. Вход посетителя в Google не нужен. Имена и контакты не собираются; случайный ID браузера позволяет оценить число уникальных браузеров.

Данные таблицы не хранятся в репозитории. Публичный обработчик принимает события, но не выдаёт накопленные записи. Его URL в `mortgage-config.js` не является секретным ключом. Чтобы отключить сбор, установите `analytics.enabled: false`.

Фотографии и отзывы предоставлены владельцем сайта. Лицензия сторонних иконок находится в `assets/contact-icons/SIMPLE-ICONS-LICENSE.md`.
