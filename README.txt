ПЕРСОНАЛЬНЫЙ САЙТ РИЭЛТОРА

Откройте index.html в браузере двойным щелчком.
Сборка, сервер и установка пакетов не требуются. Калькулятор работает без интернета.
Для перехода в сервисы связи и отправки аналитики в Google Таблицы нужен интернет.
Адрес GitHub Pages: https://tikhaziev-coder.github.io/site-rieltor/
Публикация настроена из корня ветки main. Также подходит статический хостинг.

mortgage-config.js — настройки подключения аналитики (сбор включён).
mortgage-analytics.js — отправка событий, очередь повторов и ID браузера.

tests/mortgage.test.cjs — проверки расчётов и аналитики, без внешних пакетов.
assets/ — значок сайта, фото первого экрана portrait.jpg и фото раздела
«Обо мне» about-portrait.png без логотипа tau HOUSE.

ИПОТЕЧНЫЙ КАЛЬКУЛЯТОР
Поля: стоимость, первоначальный взнос в рублях/процентах, годовая ставка,
срок до 30 лет / 360 месяцев и дата первого платежа. До 12 досрочных платежей —
разовых или ежемесячных, с сокращением срока либо уменьшением платежа.
Результат появляется по кнопке «Рассчитать»: платёж, кредит, проценты,
выплаты банку, последняя дата, экономия и помесячный график.
График можно скачать в CSV; суммы в рублях, разделитель — точка с запятой.
При изменении полей нужно нажать «Рассчитать» снова.

Модель: стандартный аннуитет при постоянной ставке и равных месячных периодах.
Проценты = остаток долга × годовая ставка / 100 / 12.
Платёж A = P × i / (1 − (1 + i)^(-n)), где i — месячная доля ставки.
При нулевой ставке A = P / n. Расчёты графика округляются до копеек.
Досрочная сумма погашает основной долг после планового платежа.
Даты служат для календаря; фактические дни, выходные, страховки, комиссии
и изменение ставки не учитываются. Итог выплат не включает первый взнос
и не является полной стоимостью кредита (ПСК). Это предварительная оценка.
Алгоритм приложения из App Store не опубликован; используется независимая
реализация стандартной формулы, а не копия внутреннего кода приложения.
Источник для проверки формулы: https://numpy.org/numpy-financial/latest/_api_stubs/numpy_financial.pmt.html

временем, введёнными параметрами, результатом и случайным ID браузера.
В «Сводке» — количество расчётов, уникальные браузеры и средние показатели.
ID браузера не определяет личность посетителя; имена и контакты не собираются.
